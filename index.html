🤖 Crash AI API

Signé SOLITAIRE HACK 🇨🇮 | IA statistique d'aide à l'analyse du jeu Crash

⚠️ Avertissement Important

Ce projet est une IA statistique d'aide à l'analyse uniquement. Il ne doit jamais promettre une prédiction garantie ou un gain certain. Les jeux de hasard comportent des risques importants.

📡 Endpoints API

GET / Status

Vérifier si l'API est en ligne

curl https://crashaiapi.onrender.com/
Réponse:
{
  "status": "Crash AI API running",
  "project": "SOLITAIRE HACK 🇨🇮"
}
POST /train Training

Entraîner le modèle sur les données du CSV

curl -X POST https://crashaiapi.onrender.com/train
Réponse:
{
  "status": "training_completed",
  "rows_used": 122,
  "model_file": "crash_ai_model.joblib",
  "accuracy": 0.56
}
POST /predict Prediction

Faire une prédiction basée sur les features fournies

curl -X POST https://crashaiapi.onrender.com/predict \ -H "Content-Type: application/json" \ -d '{ "hour": 4, "minute": 49, "second": 12, "prev_1": 5.33, "prev_2": 1.42, "prev_3": 2.31, "avg_5": 2.13, "low_count_5": 2, "high_count_10": 1 }'
Réponse:
{
  "prediction": 1,
  "confidence": 0.85,
  "signal": "ENTRÉE PRUDENTE"
}
POST /predict-batch Batch

Faire des prédictions automatiques sur tout le CSV

curl -X POST https://crashaiapi.onrender.com/predict-batch
Réponse:
{
  "total_predictions": 122,
  "statistics": {
    "ENTRÉE PRUDENTE": 51,
    "ENTRÉE TRÈS PRUDENTE": 10,
    "ATTENDRE": 61
  },
  "average_confidence": 0.7878,
  "predictions": [...]
}

🧠 Features Utilisées

  • hour: Heure du timestamp
  • minute: Minute du timestamp
  • second: Seconde du timestamp
  • prev_1: Valeur du round précédent
  • prev_2: Valeur 2 rounds avant
  • prev_3: Valeur 3 rounds avant
  • avg_5: Moyenne des 5 derniers rounds
  • low_count_5: Nombre de valeurs < 2.0 dans les 5 derniers rounds
  • high_count_10: Nombre de valeurs >= 2.0 dans les 10 derniers rounds

🎯 Signaux

  • ENTRÉE PRUDENTE: Prediction = 1 et confidence >= 0.7
  • ENTRÉE TRÈS PRUDENTE: Prediction = 1 et confidence < 0.7
  • ATTENDRE: Prediction = 0
